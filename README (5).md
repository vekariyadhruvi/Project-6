# Personal Journal Manager

## Overview

Personal Journal Manager is a simple Python program that allows users to
write, view, search, and delete journal entries. Each entry is stored in
a text file along with the current date and time.

------------------------------------------------------------------------

## Features

-   Add new journal entries
-   View all saved entries
-   Search entries by keyword or date
-   Delete all entries with confirmation
-   Menu-driven interface

------------------------------------------------------------------------

## How It Works

-   Entries are stored in a file named `journal.txt`
-   Each entry is saved with a timestamp
-   The program reads and processes the file for viewing and searching

------------------------------------------------------------------------

## How to Run

1.  Install Python 3
2.  Save the code in a file (e.g., `main.py`)
3.  Run the program: python main.py
4.  Choose options from the menu
